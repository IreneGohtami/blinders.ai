This is a [Next.js](https://nextjs.org) project bootstrapped with Supabase framework.

## Local Development

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.js`. The page auto-updates as you edit the file.

## Scripts

### Web Scraper

- Youtube videos - powered by Youtube API

The scripts are located inside `/scripts` directory and run automatically via Github scheduler which is configured inside `.github/workflows`
